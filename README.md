Esta página web sirve para controlar el uso de las salas de juego de un centro gaming. Permite ver qué salas están ocupadas o libres y gestionar la entrada y salida de los usuarios en cada una de ellas.

La aplicación está pensada para que la utilicen los trabajadores del centro. Cada usuario tendrá su propia sesión y podrá ocupar salas para clientes, pero solo podrá desocupar aquellas que él mismo haya gestionado.

Si una sala está ocupada pero no ha sido registrada por el trabajador correspondiente, el sistema la mostrará como ocupada, pero no permitirá realizar cambios sobre ella desde esa sesión.
